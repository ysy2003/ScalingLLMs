U+B0AF was added to Unicode in version 2.0 (1996). It belongs to the block Hangul Syllables in the Basic Multilingual Plane.

This character is a Other Letter and is mainly used in the Hangul script.

The glyph is a Canonical composition of the glyphs Hangul Syllable Na, Hangul Jongseong Chieuch. It has a Wide East Asian Width. In bidirectional context it acts as Left To Right and is not mirrored. In text U+B0AF behaves as Hangul LVT Syllable regarding line breaks. It has type Other Letter for sentence and Alphabetic Letter for word breaks. The Grapheme Cluster Break is Hangul Syllable Type LVT.
